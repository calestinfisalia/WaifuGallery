# Security Policy

## Supported versions

Security fixes are applied to the latest published release. Please update to the
latest version before reporting an issue when possible.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

If GitHub's private vulnerability reporting is enabled for this repository, use
the **Report a vulnerability** option on the repository's Security tab. Otherwise,
open an issue asking for a private reporting channel, without including
vulnerability details. Once you have a private channel, include:

- The affected version, platform, and relevant component.
- A description of the potential impact.
- Steps to reproduce or a proof of concept, avoiding access to other people's
  data or services.

Please allow time for the maintainer to investigate and prepare a fix before
publicly disclosing the issue. This project is maintained on a best-effort basis;
there is no guaranteed response or remediation timeframe.
